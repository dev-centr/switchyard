= Switchyard
:description: Windows file-association switchyard for open, icon, and thumbnail tracks.

Switchyard snapshots and guards Windows file-association **tracks** (open verb, static icon, thumbnails) so installers cannot quietly rebrand your Explorer icons — and so smarter open routing can land later without hijacking the yard.

Roles (not alternate product names): **file router** (debranded) and **app broker** (architecture talk). Brand stays Switchyard.
